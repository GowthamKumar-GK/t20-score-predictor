# 🏏 T20 Score Predictor — Streamlit App

Predicts T20 innings final score from Powerplay (overs 1–6) stats using Machine Learning.

## Live App
👉 After deployment: `https://your-username-t20-predictor.streamlit.app`

## Run Locally (Ubuntu / any OS)
```bash
# Step 1 — Install
pip install -r requirements.txt

# Step 2 — Run
streamlit run app.py
```
Opens at: http://localhost:8501

## Deploy to Streamlit Cloud (Free)
1. Push this folder to GitHub
2. Go to share.streamlit.io
3. Connect GitHub → select repo → select app.py
4. Click Deploy → get free link!

## Pages
- 🎯 Predict Score — enter PP stats, get final score prediction
- 📊 Model Metrics — R², MAE, RMSE for all 5 models
- 🔍 EDA Charts — visualizations and correlations
- 📋 Dataset — explore and download the data

Python · Streamlit · Scikit-learn · Pandas · Matplotlib · Seaborn
